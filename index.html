Параметры

Ярче порога — гранула продукта; темнее — фон или тёмное включение. Основной ползунок: двигая его, вы двигаете границу «брак/норма».
Нормализация перед анализом. Для слабоконтрастных кадров с камеры на ленте.
Сдвиг яркости. Влияет только на сегментацию, геометрию не трогает.
Гранулы меньше этого размера отбрасываются как шум камеры / пыль.
Технологический допуск для решения PASS/FAIL: по неоднородности размеров и по доле тёмных включений.
